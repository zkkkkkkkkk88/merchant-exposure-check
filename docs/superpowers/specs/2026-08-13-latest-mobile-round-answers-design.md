# 上一轮手机实测问答展示设计

## 目标

在“上一轮已保存成功”区域提供可展开的上一轮问答，帮助商家结合豆包原回答查找未被推荐、名称不一致或竞品信息更充分等问题。

## 交互

- 增加“查看上一轮问题与答案”折叠入口，默认收起。
- 展开后按 Q1、Q2、Q3 顺序显示问题、完整豆包回答、已确认提及状态和目标商家排名。
- 没有回答文本时明确显示“本题未保存回答内容”，不展示空白卡片。
- “开始新一轮”行为保持不变；历史问答只读，不参与新一轮表单提交。

## 数据

- 扩展现有手机实测 workspace 响应，增加 `latestRoundAnswers`。
- 数据直接来自最近一轮已确认记录及其验证题、结果，不新增数据表，也不复制保存内容。
- 每项包含题号、问题、回答、提及级别、提及标签和目标商家排名。
- 没有已确认轮次时返回空数组。

## 范围与隔离

- 对所有行业使用同一展示结构，不加入口腔行业专属文字。
- 仅展示当前所选商家的最近一轮，不能跨商家读取。
- 本次不增加完整历史列表、编辑回答或删除记录功能。

## 验证

- 后端测试确认 workspace 返回按题号排序的上一轮问题与答案。
- 前端测试确认完成状态下默认折叠，点击后显示问题、原回答和提及结果。
- 运行相关前后端测试、前端生产构建，并在本地页面确认折叠交互。
