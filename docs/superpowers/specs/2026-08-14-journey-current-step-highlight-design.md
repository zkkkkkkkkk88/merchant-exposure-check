# 六步旅程当前页面高亮设计

## 目标

让用户一眼区分“当前所在页面”和“步骤完成状态”。当前页面高亮由实际 URL 决定，不使用后端返回的下一步字段代替。

## 路由映射

- `/merchants` 与 `/merchants/:id`：商家画像
- `/queries`：问题策略
- `/platform-audits`：平台查缺
- `/mobile-checks`：手机实测
- `/mobile-checks#improvement-playbook`：执行优化
- `/mobile-checks#retest-comparison`：同题复测
- `/delivery-report`：不强行点亮六步中的某一步

浏览器锚点变化时立即更新当前步骤，不要求刷新页面。

## 视觉与可访问性

- 当前步骤优先于完成状态显示：浅橙背景、顶部粗橙线、实心橙色编号、加粗文字。
- 已完成但非当前步骤保持绿色。
- 可执行但非当前步骤保持橙色描边。
- 未开始步骤保持灰色。
- 当前步骤链接添加 `aria-current="step"`，供键盘和辅助阅读软件识别。

## 测试

- 平台查缺页面只高亮“平台查缺”。
- 手机实测页面只高亮“手机实测”。
- 切换到两个锚点时分别高亮“执行优化”和“同题复测”。
- 当前步骤与已完成步骤同时存在时，当前样式优先且完成数据不被修改。
