# 手机版豆包推荐率提升方案设计

## 目标

将手机版豆包的三题验证结果转化为商家能理解、能执行、能复测的提升方案。系统回答四个问题：本轮表现如何、为什么竞品更容易被推荐、本周先做什么、完成后是否真的改善。

本功能只使用已确认的手机实测结果、商家画像和来源证据，不新增外部模型调用，不承诺平台排名或必然被推荐。

## 页面结构

手机实测页在指标和来源差距之后增加“推荐率提升方案”，按以下顺序展示：

1. **本轮诊断结论**：用一句话概括提及次数、推荐层级和缺失场景，例如“3题出现1次，仅在综合推荐中排第5；口碑好、评价稳定两个场景未出现”。
2. **竞品胜出原因**：最多展示3家竞品，每家最多3个有证据的优势。依据来自豆包原回答中的明确描述或已确认来源；没有证据时显示“本轮只确认其被推荐，原因待核实”，不得自行补充。
3. **本周优先3项行动**：按影响范围、证据强度和商家可控性排序，每项包含触发依据、具体步骤、需要准备的资料、表述示例和完成标准。
4. **内容示例**：每项行动最多给2个可直接改写的标题或资料结构。示例必须基于已确认事实；未确认的医保、医生资质、设备和价格不得写成既成事实。
5. **同题复测**：继续使用当前固定3题，展示上轮与本轮的提及率、首批推荐率、出现题目和推荐层级变化。

## 证据与判断规则

### 目标商家诊断

- `none` 表示该题未提及目标商家。
- `supplementary` 表示目标商家被提及，但不是首批或主要推荐。
- `primary` 表示目标商家处于首批推荐。
- 诊断必须列出具体问题，不只显示百分比。
- 目标名称使用现有实体归一化规则，简称“皓雅口腔门诊”等继续归并到“澜沧皓雅口腔门诊部”。

### 竞品优势

- 从各题回答摘要中的竞品条目提取冒号后的短描述，形成候选优势。
- 相同含义合并，例如“医保定点”和“可医保”归为医保信息。
- 只展示在至少一题中出现的优势，并标注来源问题编号。
- 已确认来源可以增强证据等级；没有来源时标记为“来自豆包回答，待公开来源核实”。
- 不把“公立一定更好”“评价稳定”等推断当成事实，除非原回答或来源明确支持。

## 行动生成规则

系统使用确定性规则生成候选行动，再排序取前3项：

1. **名称一致性**：目标以简称出现或存在多个写法时，建议统一正式名称，并在正文自然保留常用简称。
2. **场景缺失**：某题未提及时，按问题场景生成对应行动，例如“口碑好”缺失时优先补充经营年限、真实评价摘要、消毒流程和医生履历等可验证资料。
3. **竞品证据差距**：竞品反复出现医保、设备、医生、服务项目或经营稳定性，而目标缺少同类公开证据时，生成事实补齐行动。
4. **来源缺口**：来源对比表存在明确差距时，建议优先维护工商登记、机构介绍页、招聘页、本地媒体或抖音公开内容等对应渠道。
5. **补充推荐升级**：目标多为补充推荐时，优先增强与题目场景直接相关的差异化证据，而不是泛泛增加宣传内容。

每项行动包含：

- `title`：可理解的行动标题。
- `why`：触发该行动的具体题目、回答或来源差距。
- `steps`：2至4个执行步骤。
- `materials`：需要准备的事实和资料。
- `examples`：最多2个内容标题或资料结构示例。
- `completionCriteria`：可检查的完成标准。
- `confidence`：`confirmed`、`answer_only` 或 `needs_verification`。

排序优先级：跨多题缺失 > 单题缺失；已确认来源差距 > 仅回答描述；商家可维护渠道 > 第三方不可控渠道；名称和基础事实问题优先于内容扩展。

## 数据与接口

扩展手机工作区响应，新增：

- `diagnosis`：本轮结论、逐题结果和目标商家出现位置。
- `competitorReasons`：竞品名称、优势、证据题目和证据等级。
- `actions`：排序后的3项行动。
- `comparison`：存在上一轮确认结果时返回同题前后变化，否则为 `null`。

行动由后端服务根据已保存的确认结果生成，不另建人工编辑数据库表。历史轮次继续保持不可变，复测比较按相同验证集题目或相同规范化问题文本匹配。

## 空状态与错误处理

- 没有确认轮次时不显示行动方案，只提示完成一次三题实测。
- 某轮没有来源审计时，仍可根据回答生成低证据等级行动，但必须标注“待公开来源核实”。
- 回答摘要不足以解释竞品原因时，只显示“被推荐但原因待核实”，不得猜测。
- 不足3项可靠行动时只展示实际可支持的数量，不用泛化建议凑满3项。
- 复测题目不一致时不直接比较百分比，提示使用同一3题验证集复测。

## 当前案例预期

对澜沧皓雅口腔门诊部当前一轮结果，页面至少应显示：

- 3题出现1次，属于补充推荐；“口碑好”和“评价稳定”场景未出现。
- “皓雅口腔门诊”归并为目标商家，而不是竞品。
- 第一人民医院、中医医院、王天佑口腔等作为竞品；只提取回答中明确出现的医保、设备、经营时间或诊疗能力描述。
- 优先行动聚焦名称统一、口碑稳定证据和关键服务事实；没有确认的医保或设备不得写成皓雅已有优势。

## 验收标准

- 每条诊断和行动都能追溯到至少一个问题结果、回答摘要或已确认来源。
- 页面最多展示3家竞品、每家3个原因、3项行动和每项2个示例。
- 无证据内容不会被写成确定事实。
- 当前真实数据正确显示1/3提及和两个未出现的场景。
- 完成第二轮同题验证后能显示前后变化；不同题集不会被错误比较。
- 后端服务、接口、前端展示和当前案例均有自动化测试。
