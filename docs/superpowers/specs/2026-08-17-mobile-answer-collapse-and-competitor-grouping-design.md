# 移动实测答案折叠与竞品归并设计

## 目标

1. 用户阅读完上一轮完整答案后，可以在答案列表底部直接收起内容。
2. 同一家竞品即使带有不同地区、机构后缀或括号说明，也应合并统计并正确展示。

## 答案折叠交互

- 保留现有顶部“查看上一轮问题与答案”入口。
- 在最后一道答案下方增加“收起答案”按钮。
- 点击按钮后关闭当前答案详情，并把顶部入口滚动到可见区域，方便用户确认内容已收起。
- 按钮仅在答案详情展开时出现，使用真实按钮元素并提供明确的无障碍名称。

## 竞品归并与排序

- 竞品身份比较忽略地区词、口腔机构通用后缀、公司后缀和括号内描述。
- 同一竞品在同一道题中多次出现只计一次；跨题累计出现题数。
- 竞品按出现题数降序排列；题数相同时按首次出现在答案中的顺序排列。
- 只展示至少在两道题中出现的前三家竞品。
- 明确排除目标商家本身，避免目标商家被归入竞品卡片。
- 卡片保留答案中首次出现的完整名称作为展示名称，并展示出现题数及答案中的实际理由。
